## My Reflection

การนำ AI Agent มาร่วมทำงานตลอดทั้ง Sprint 4 ของ TokTickIT ตั้งแต่รอบวางแผน ออกแบบสเปก การเขียนโค้ด ไปจนถึงรอบ Peer Review และการทำ Regression Hardening ทำให้ผมได้รับบทเรียนและข้อคิดและเทคนิดดีๆหลายประการ

- การใช้ AI Agent มาช่วยสังเคราะห์และปรับปรุงเอกสารสเปกทั้งชุด (specification.md, ui-spec.md, api-spec.md, tests.md) ให้เป็น Single Source of Truth ก่อนเริ่มเขียนโค้ดจริง ช่วยประหยัดเวลาและลดการรื้อโค้ดซ้ำซ้อนในภายหลังได้อย่างมหาศาล

- การใช้ Agentic AI จะมีประสิทธิภาพสูงสุดเมื่อเรา:
  1. กำหนดขอบเขตและสัญญาที่ชัดเจน ผ่านเอกสารบริบทอย่าง .agents/LAB4AGENTS.md
  2. มี Automated Test Harness เป็น Safety Net ที่รัดกุม ทั้ง Unit Tests, Integration Tests และ E2E Suites ทำให้เมื่อ Agent ปรับปรุงโค้ด เราสามารถตรวจจับ Regression หรือผลข้างเคียงได้ทันที
  3. ตรวจสอบโค้ดอย่างมีวิจารณญาณ ไม่ปล่อยให้ AI เขียนโค้ดหรือเขียนเทสต์ที่หลวมเกินไป การคอยตรวจสอบ Diff และผลการรันเทสต์อย่างสม่ำเสมอทำให้ผลงานสุดท้ายของ Lab 4 ออกมามีคุณภาพสูง แข็งแกร่ง และผ่านเกณฑ์การประเมิน 60/60 อย่างสมบูรณ์
