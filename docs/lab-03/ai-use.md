## My Reflection

หลังจากที่ได้ใช้ agent มาเป็นผู้ช่วยในการทำ project ใน lab3 แล้ว ไม่ว่าจะเป็นเรื่อง planning, coding, testing ทำให้ผมได้ตระหนักว่าการกำหนดทิศทางและกรอบในการทำงานของ AI มีความสำคัญมากๆ ที่จะทำให้ agent มีประสิทธิภาพมากขึ้น

เรื่องที่น่าคิดที่ผมคิดได้หลังจากทำ lab นี้คือ ตัวผมที่มี gemini-pro ไม่เคยต้องคิดเกี่ยวกับ token มากก่อนเพราะว่า plan นี้มี token ให้ใช้เยอะเกินพอ แต่ในอนาคตถ้าผมเปลี่ยน model และต้องจำกัด token ที่ใช้งานคงจะทำให้ workflow ในปัจจุบันต้องเปลี่ยนไป
